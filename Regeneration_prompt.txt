PROJECT REGENERATION PROMPT FOR SKILLPATH ACADEMY HTML FILES
================================================================

PROJECT OVERVIEW:
SkillPath Academy is a professional skills-based course platform website. It is a demo project for educational purposes. The website allows users to browse courses, register interest in courses, view their registrations, and manage registration data locally using browser storage.

TECHNOLOGY STACK:
- HTML5 with semantic markup
- CSS (modular structure with separate stylesheets)
- JavaScript (vanilla, no frameworks)
- Local browser storage (localStorage) for data persistence
- Accessibility features (skip links, ARIA labels, semantic HTML)

PROJECT STRUCTURE:
- 6 HTML files in root directory
- CSS files in /css directory
- JavaScript files in /js directory
- No backend server - all data stored locally in browser

IMPORTANT NOTES:

- This is a demo/educational project
- Mobile responsive design required (hamburger menu on mobile)
- Accessible design (WCAG compliance)
- Semantic HTML5 markup

- The course data structure should support: ID, name, description, category, status (Open/Closed), mode (Online/Classroom/Hybrid), intakes (multiple dates), instructor, duration, level

COURSE DATA STRUCTURE (for reference when generating):
Each course should have:
- ID (unique identifier)
- Name
- Description
- Category (e.g., Technology, Business, Healthcare, Engineering, Design, Communication)
- Status (Open, Closed)
- Mode (Online, Classroom, Hybrid)
- Available Intakes (array of dates)
- Instructor name

- Level (e.g., Beginner, Intermediate, Advanced)
